# Edward Amirain


Software & applied AI engineer. Founder of [Vaynerov Technologies](https://vaynerov.com), a software studio building mobile apps, SaaS platforms and applied AI products. I founded Vaynerov in January 2024.


My work spans product architecture, development and the engineering around AI: validating outputs, keeping business rules explicit and making useful interfaces. Read my [founder biography and selected engineering work](https://vaynerov.com/about#founder).


## Selected client work

[White Knight Auction](https://vaynerov.com/work/white-knight-auction) uses a platform Vaynerov Technologies designed, built and runs. A bidder can follow a lot from the catalog into the live sale, and the auctioneer and clerk work from the same sale record.

Our [engineering note on concurrent bids](https://vaynerov.com/articles/three-hundred-bidders-two-seconds) explains how we checked bid ordering and the prices shown on simulated screens. Across 38 test runs, all 29,151 simulated bids were accounted for.

## Engineering notes

[Who can ship the next version?](https://gist.github.com/vayner0v/6e6765cc144f87b2d9fbd35219bd2f13) gives software buyers a handover exercise they can run with their team. It is available in English, Simplified Chinese and French.

[When does an online auction lot actually sell?](https://telegra.ph/When-does-an-online-auction-lot-actually-sell-11-27) follows a bid from its arrival to the auctioneer’s decision and explains which event the screens should trust.

[What to check before retrying an uncertain operation](https://www.linkedin.com/feed/update/urn:li:activity:7519656780348461057/) is a short design checklist for lost responses, operation identifiers, retention windows and confirming outcomes. It links to the Amazon Builders' Library for the underlying idempotency discussion.
